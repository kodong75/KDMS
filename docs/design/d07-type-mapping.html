IDENTITYGENERATED BY DEFAULT AS IDENTITY, 시작·증가값 유지. 정수 타입이 아니면 오류identity.setval: from_ident_current (전환 때 setval)A09

3. 값 규칙 (DDL 은 바꾸지 않음)

규칙기본값선택지근거(KIS)

NUL 문자failfail · strip · replace(U+FFFD). 기본은 멈춰서 알리고, 확인한 컬럼만 replace(DEC-27)A02
대소문자keepkeep · upper · lower
센티널 날짜(1753-01-01 · 1900-01-01 · 9999-12-31)keepkeep · null · infinityA08
소수 초 반올림half_updatetime2 · time · datetimeoffset 7자리 → 6자리A06

값을 바꾸는 규칙을 쓰면 검증도 같은 규칙으로 원천을 정규화한다. 바꾸지 않은 컬럼의 차이는 해시에 그대로 잡힌다(KIS normalization §0).

4. 시험 원천 KDMS_MOCK 결과

  • 컬럼 타입은 7개 테이블 55개 컬럼 모두 KIS mock.sql 과 같다(Mac 에서 SourceCatalogIT · TargetDdlIT 통과).
  • 작업별 덮어쓰기(config/kdms-rules.yml): 계산 컬럼 dbo.rating.rating_rank(원천 CI 비교에 맞춰 upper(rtrim(…))), dbo.research_doc.file_ext 의 PG 식.
  • 예상 경고 9건(트리거, uniqueidentifier · rowversion 타입, 함수 기본값 4종, 자동 변환 안 하는 객체), 주의 3건(CI 비교, 끝 공백, CP949 바이트).
  • NUL 문자: 기본 fail 을 유지하고 dbo.issuer.issuer_nm 만 config/kdms-rules.yml 에서 replace(DEC-27, issues.md A01·A02).
